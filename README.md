# 🍕 D-Pizza Online Ordering Website

A full-stack online pizza ordering web application built with **Python Flask (Backend)** and **ReactJS / Vite (Frontend)**.
## 🛠️ Prerequisites
Make sure you have the following installed on your computer before getting started:
* Node.js (for running the Frontend)
* Python (for running the Backend)
* PostgreSQL (for database management)

#🚀 Getting Started

#1. Clone the Repository
  Open your terminal (PowerShell or CMD) and run:
  
  git clone [https://github.com/ounpunleu918-design/project-I_pizza_online.git](https://github.com/ounpunleu918-design/project-I_pizza_online.git)
  cd project-I_pizza_online

# Setup and Run Backend (Flask)
  cd Backend
# Install Python dependencies
  pip install -r requirements.txt
# Run the Flask application
  python main.py
  
# Setup and Run Frontend (ReactJS / Vite)
cd Frontend

# Install Node.js packages
  npm install

# Start the development server
  npm run dev
